# camera — RAW photo library brain

`~/library/camera` holds RAW files and videos, one folder per shoot per day. Not a git repo (files are 30–60 MB each). The cold copy lives in R2.

System context: `~/claude-computer/docs/`.

## Layout

```
camera/
  YYYY/
    YYYY-MM-DD_<shoot>/
      YYYYMMDD_HHMMSS_<frame>.RAF      renamed at ingest
      YYYYMMDD_HHMMSS_<frame>.RAF.xmp  darktable sidecar (edits live here, as text)
      SHA256SUMS
  index.csv                            exiftool metadata, one row per file (generated)
  INDEX.md                             human summary (generated by you)
```

## Jobs

1. **Ingest**: card in → ask for a shoot name → `camera-ingest <card> <shoot> --dry-run` → then for real (`--eject` if I want). It copies, checksums, renames, indexes, and pushes the cold copy. Never deletes from the card.
2. **Organise**: ratings, tags and culling-by-metadata go into darktable (sidecars / `library.db`). **You don't make creative edits and you don't delete photos.**
3. **Find**: "4-star shots from the coast last spring" → query `index.csv` and darktable's `library.db` (SQLite: `~/.config/darktable/library.db`) → list → export with `darktable-cli <raw> <xmp> <out.jpg>`.
4. **Restore**: if a folder was pruned locally, pull it back from `r2:<bucket>/library/camera/<YYYY>/<folder>`.
5. **INDEX.md**: after each ingest, regenerate the summary: shoots per year, file counts, date ranges, camera/lens.

## Rules

- The cold push is one-way. Never delete a local folder unless I ask, and only after `rclone check` against R2 passes.
- `books/` and `comics/` next door belong to Calibre. Don't touch them except to include them in the cold push.
